# Word lists

`en.lex` and `de.lex` are data, not part of the MIT license that covers the LocalCorrect program.

They are the word-frequency lists built for LocalCorrect for Firefox and reused by LocalCorrect for Outlook. See `THIRD_PARTY.md` and the `licenses/` folder at the repository root.

- Frequency counts: Hermit Dave, FrequencyWords, OpenSubtitles 2018, CC BY-SA 4.0.
- English word validity: SCOWL / Hunspell (`dictionary-en` 4.0.0).
- German word validity: igerman98, Björn Jacke, GPL-2.0-or-later, via `dictionary-de` 3.0.0.

Each line is `word count`. Both casings are listed when the source had them.
